## 透镜元数据结构

每个透镜包含以下字段：

```javascript
{
  id: 'Lens01',                    // 透镜ID
  name: 'English Name',            // 英文名称
  nameZh: '中文名称',               // 中文名称
  region: 'East Asia',             // 所属文化区域
  tags: [],                        // 标签（当前为空，预留扩展）
  coreTraits: '...',               // 核心特质
  interpPref: '...'                // 解读偏好
}
```

在推理时，`coreTraits` 和 `interpPref` 会注入到 User Prompt 中，作为 AI 的认知滤镜。

#### Lens01 — 中国传统家文化资本/价值决策者

**英文名：** China Traditional Family-Capital Decision Makers

**核心特质：**

基于点击/停留/互动的行为驱动模型；强化"可传播性"而非"真实性"；偏好情绪强度与冲突内容；对内容进行概率性排序而非语义理解。

**解读偏好：**
更关注"用户是否会点/停留"而非内容意义；会放大极端或高情绪信号内容；对文化背景理解有限，依赖统计模式；容易形成信息茧房效应。

---

#### Lens26 — AI 大语言模型视角

**英文名：** AI Large Language Model

**核心特质：**
基于概率生成文本而非真实理解；强依赖上下文与提示结构；倾向生成"合理答案"而非"唯一正确答案"；对文化隐含意义敏感但不稳定。

**解读偏好：**
优先生成语义连贯内容；会"补全信息缺失"；容易将复杂文化简化为模式；在无约束下可能泛化解释。

#### Lens27 — 法律合规视角

**英文名：** Legal Lens

**核心特质：**
关注版权、隐私、肖像与数据合规；强规则导向与风险规避；偏好可追溯、可证明的信息结构；对模糊表达高度敏感。

**解读偏好：**
优先识别潜在侵权与风险点；倾向要求明确来源与授权；对"误导性表达"高度警惕；关注跨国法律差异。

---

#### Lens28 — 伦理公平视角

**英文名：** Ethical Lens

**核心特质：**
关注偏见、公平性与社会影响；强价值判断但依赖语境；重视弱势群体与结构性问题；对隐性操控与引导敏感。

**解读偏好：**
会识别潜在歧视或价值倾向；更关注"影响谁"而非"是否正确"；容易放大社会责任议题；对内容动机进行道德解读。

---

#### Lens29 — 历史长周期视角

**英文名：** Historical Lens

**核心特质：**
以时间周期理解事件意义；偏好结构性与长期趋势；强比较分析能力（相似历史事件）；关注"当下在历史中的位置"。

**解读偏好：**
将事件放入长期演化框架；会寻找历史类比与模式；关注因果链而非单点事件；容易弱化即时情绪解读。

---

#### Lens30 — 生态与系统危机视角

**英文名：** Ecological & Crisis Lens

**核心特质：**
关注系统性风险与连锁反应；偏好宏观结构（环境/经济/战争/疫情）；强烈的风险敏感性；重视不可逆后果。

**解读偏好：**
优先识别"潜在危机信号"；会放大长期负面外溢效应；将局部事件映射到系统结构；偏好预警式分析而非解释性叙事。

## AI 输出格式

每个透镜的 AI 输出为一行 JSON：

```json
{
  "lensId": "Lens01",
  "firstImpression": "一句话直觉反应（20-40字）",
  "noticed": [
    {
      "detail": "具体观察内容（40-100字）",
      "whyItMatters": "为什么这个细节重要（20-50字）"
    }
  ],
  "ignored": ["忽略的内容1", "忽略的内容2"],
  "reason": "更深层的文化解码（80-150字）"
}
```

解析时兼容新旧两种格式：
- `noticed`：字符串数组（旧）或对象数组（新，含 detail + whyItMatters）
- `ignored`：字符串数组或对象数组（含 detail/text 字段）
